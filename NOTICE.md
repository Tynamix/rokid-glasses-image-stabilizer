# Third-Party Components

The application code in this repository is separate from the proprietary
native libraries required at build time.

The following components are not included in this repository:

- Rokid `libmedia_process.so`
- Arcsoft `libarcsoft_videostabilizer.so`
- Arcsoft `libnighthawk.arcsoft.so`
- Other native libraries distributed by the Rokid application

These files must be supplied by the user from a legally obtained APK set and
remain subject to their original licenses. Do not redistribute them without
permission from the respective copyright holders.
